# Personal Finance Manager


## OVERVIEW
This is a simple Personal Finance Manager made by me using Python.
The idea of this project is to help users track their income and expenses in an easy way.
I have kept the project small and easy to understand, focusing mainly on modular code and file handling.


## FEATURES
- Add income and expense entries
- Store all transactions in a file
- Displays a clean financial report
- Shows:
  - Total income  
  - Total expenses  
  - Remaining balance  
- Menu-based terminal interface
- Modular code structure 
- Simple and Easy to Understand


## TOOLS USED
- Python
- Basic file handling
- Functions and modular programming
- Simple text-based input/output


## STEPS TO INSTALL AND RUN THE PROJECT
1. Download or clone the project folder.
2. Make sure all '.py' files are in the same directory.
3. Open a terminal or command prompt inside the folder.
4. Run the command : The menu will appear and you can start adding or viewing transactions.


## INSTRUCTIONS FOR TESTING
Start the program and add 2 or 3 sample income and expense entries.
View the transactions to check if they are saved correctly or not.
Save and Exit.
You will be able to see all your activity in 'finance_data.csv' file.
You can also delete the transactions if you want.
