# Problem statement
Manual money management can be confusing as income and expenses add up over time.
This project is aimed at creating a simple Python program that will help track day-to-day financial activities in one place.


# Scope of the project
- Recording income and expense entries
- Saving all records in a file
- Displaying a basic financial summary


# Target users
- Students who want to keep an eye on their spending
- Someone who wants a very simple offline tool to record transactions
- Beginners learning Python file handling and modular programming


# High-Level features
- Add new transactions (income or expense)
- Store data permanently using text files
- Generate a summary showing total income, total expenses, and remaining balance
- Easy-to-use menu navigation
